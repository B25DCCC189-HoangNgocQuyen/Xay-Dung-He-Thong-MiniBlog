# MiniBlog

Ứng dụng blog làm bằng React + TypeScript (Vite).

## Chức năng
- Xem danh sách bài viết (lấy từ jsonplaceholder), tìm kiếm theo tiêu đề
- Xem chi tiết bài viết + bình luận
- Đăng nhập (tài khoản: admin / 123456)
- Viết bài mới (phải đăng nhập), bài viết lưu vào localStorage
- Chế độ sáng / tối
- Trang 404

## Chạy project
```
npm install
npm run dev
```

## Ghi chú
- Có tham khảo slide trên lớp và dùng AI để hỏi / sửa một số chỗ.
